## 📖 Sobre o projeto

O **Garage Hair** é um projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento Web**, com o objetivo de criar um site completo utilizando tecnologias Front-End.

A proposta vai além de apresentar os serviços de uma barbearia. O projeto busca integrar conceitos de:

- 🌿 Sustentabilidade;
- ♻️ Consumo consciente;
- 💧 Uso responsável de recursos;
- ♿ Acessibilidade;
- 🤝 Inclusão e impacto social;
- 💈 Cuidado pessoal e bem-estar.

O site é composto por **10 páginas interligadas**, desenvolvidas com HTML5 semântico, CSS, Bootstrap e recursos de acessibilidade.

> **Observação:** a Garage Hair apresentada neste projeto é uma proposta fictícia desenvolvida exclusivamente para fins acadêmicos.

---

## 🎯 Objetivo

Desenvolver uma aplicação web responsiva, acessível e visualmente consistente, aplicando conceitos estudados durante a disciplina de Desenvolvimento Web.

O projeto também busca demonstrar como uma empresa pode incorporar práticas de sustentabilidade e responsabilidade social em sua identidade e em suas atividades.

## ♿ Acessibilidade

A acessibilidade é um dos pilares centrais do projeto.

Entre as práticas adotadas estão:

- Uso de HTML5 semântico;
- Textos alternativos em imagens;
- Navegação por teclado;
- Estados visíveis de foco;
- Contraste adequado;
- Associação correta entre campos e labels;
- Design responsivo;
- Uso adequado de hierarquia de títulos;
- Recursos ARIA quando necessários.
