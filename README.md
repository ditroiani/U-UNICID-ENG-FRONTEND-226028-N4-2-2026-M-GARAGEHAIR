## 📖 Sobre o projeto

O **Garage Hair** é um projeto acadêmico da disciplina de **Desenvolvimento Web**, com a proposta de criar o site de uma **barbearia sustentável e inclusiva**.

O projeto une:

- 🌿 Sustentabilidade  
- ♿ Acessibilidade  
- 🤝 Impacto social  
- 💈 Identidade visual moderna  

> **Observação:** este projeto possui finalidade acadêmica. Algumas informações podem ser fictícias ou simuladas.
